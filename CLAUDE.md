# Pingüino Resortera — memoria del proyecto

Este vault de Obsidian es la memoria compartida del juego de Roblox. Se sincroniza por GitHub (Arclyne/pinguino-memory).

Al empezar cualquier sesión:
1. Leer `00 Índice.md` (estado actual y siguiente paso).
2. Leer `Contexto para Claude.md` y seguir sus reglas.
3. Leer la última nota de `06 Bitácora/`.

Al terminar, actualizar la bitácora, las decisiones y el estado del índice, como indica `Contexto para Claude.md`.

Los archivos de esta carpeta son la fuente de verdad: el contexto guardado en el proyecto de Claude puede estar desactualizado.
