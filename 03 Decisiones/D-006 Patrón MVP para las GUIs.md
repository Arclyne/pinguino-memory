# D-006 Patrón MVP para las GUIs #decidido

## Decisión
- Todas las GUIs del juego siguen el patrón **MVP (Model–View–Presenter)**.
- Todo el código sigue los principios **SOLID**.
- **Sin comentarios innecesarios** en el código: nombres declarativos en su lugar.
- **Código en inglés** (identificadores, scripts, módulos).

## Contexto
Definido por Angel para mantener las GUIs ordenadas y fáciles de cambiar.
